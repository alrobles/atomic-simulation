¿Cómo interactúan?

Las moléculas son cuerpos rígidos con un oxígeno y dos hidrógenos. El modelo calcula fuerzas entre vecinas: una atracción de corto alcance tipo Lennard‑Jones y una atracción direccional simplificada para los puentes de hidrógeno. La orientación también puede girar por el torque.

Arranca desde una configuración sólida, líquida o gaseosa y cambia T*. Al calentar, las moléculas ganan movimiento y la estructura se desordena; al enfriar, las atracciones las agrupan.

Estrategia de cómputo: una cuadrícula espacial busca solo moléculas cercanas. Así evitamos comparar cada molécula contra todas las demás (O(N²)); la búsqueda de vecinos se aproxima a O(N) para una densidad fija. Son 42 moléculas para que el movimiento fluido funcione en una laptop sin GPU especial.

Modelo cualitativo 2D, no simulación cuantitativa del diagrama de fases. T* es temperatura reducida, no kelvin; las dimensiones y velocidades no están a escala temporal real. No se calculan electrones, enlaces covalentes ni cambios químicos: cada H₂O conserva su forma. El puente de hidrógeno se representa con una interacción efectiva orientacional inspirada en la estructura del agua.
